# Perintah yang dia mengerti

Ucapkan atau ketik, dalam bahasa Indonesia atau Inggris; semua ini tidak butuh AI. Namanya dan pembuka sopan boleh
("Halo Capri, tolong…", "can you…"), menggabungkan beberapa dengan "lalu", "terus", "dan" juga boleh ("buka notepad lalu
ketik halo"). Kalau diucapkan dengan kata lain, modelnya mencari perintah mana yang kamu maksud
([dengan kata-katamu sendiri](FITUR.md#perintah-yang-lebih-pintar)).

## Hotkey

| Hotkey | Fungsinya |
| --- | --- |
| Ctrl+Alt+C | Simpan dia / panggil lagi, turun dari cursor, hentikan glitch |
| Ctrl+Alt+T | Chat-nya |
| Ctrl+Alt+V | Bicara dengannya (mikrofon) |
| Ctrl+Alt+L | Dia melihat layarmu |
| Ctrl+Alt+S | Pengaturannya |
| Esc (saat dia mengetik) | Berhenti mengetik |

Semuanya bisa diubah di Pengaturan › Advanced.
